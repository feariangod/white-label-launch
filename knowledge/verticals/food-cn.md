# 品类知识 · 中国食品 / 食养 / 大健康合规红线

> 本文件属于 knowledge/verticals/（品类知识库）：只装品类事实，不装流程方法。
> 用法：定配方前用它排雷（原料法规身份），写内容前用它过滤（红线词库）。条文以现行有效版本为准，执行前核对最新修订与执法动态。新品类立项时，按本文件的结构（法律底线 → 红线词库 → 原料/物料身份查询法 → 执行机制 → 灰区教训）新建对应品类文件。

## 一、三条法律底线

| 依据 | 核心内容 | 对白牌的含义 |
|---|---|---|
| 《广告法》第 17 条 | 非医疗、药品、医疗器械广告，不得涉及疾病治疗功能，不得使用医疗用语或易与药品混淆的用语 | 普通食品不能说任何「病」和「治」 |
| 《食品安全法》第 71、73 条 | 标签说明书不得含虚假内容、不得涉及疾病预防治疗功能；广告不得宣称保健功能（非保健食品） | 包装、详情页、直播间全口径适用 |
| 《食品安全法实施条例》第 38 条 | 保健食品之外的其他食品不得声称保健功能 | 「补气血」「助眠」「养胃」全部禁用 |
| 《广告法》第 9 条 | 不得使用「国家级」「最高级」「最佳」等用语 | 绝对化用语全面禁用 |

执法现实：市场监管已对各品类「症状宣称」开出罚单，且执法会蔓延——同品类别人被罚，就是下一个轮到自己的预警。

## 二、红线词库与合规替代

| 类别 | 禁用 | 合规替代 |
|---|---|---|
| 疾病/症状词 | 痛经、宫寒、失眠、便秘、手脚冰凉、湿气重 | 那几天、想喝热的时候、晚安时刻、睡前收场 |
| 功效词 | 补气血、安神、助眠、养胃、祛湿、调理、改善 | 说食材不说功效（「红枣桂圆枸杞」可以，「补气血」不行） |
| 医疗用语 | 治疗、疗效、适用 xx 病症人群 | 说时刻与画面 |
| 绝对化 | 最有效、第一、根治 | 无替代，全禁 |
| 体质/禁忌 | 适合 xx 体质、孕妇不宜（包装层面） | 仅用于内部客服分层话术，主动告知，不上包装 |

**核心转换手法：把「症状」换成「时刻」，把「功效」换成「食材」，把「适用人群」换成「画面」。**

## 三、原料法规身份：查询方法 + 分类框架（定配方前排雷）

**硬指令：下表为 2026-08 快照，仅演示「怎么查、怎么归类」。实际执行时，配方里每一味原料都必须重新检索国家卫健委现行《按照传统既是食品又是中药材的物质目录》及相关新食品原料公告原文，禁止直接引用本表的归类和限量数字。法律会修订，快照会过期。**

查询路径：国家卫健委官网「食药物质目录」与「新食品原料（新资源食品）公告」→ 核对原料是否在目录、用量限制、不适宜人群 → 把公告名称与年份记入证据。

| 身份类别 | 含义 | 示例（2026-08 快照，须重新核实） |
|---|---|---|
| 普通食品原料 | 无限制 | 谷物、果蔬、奶粉等 |
| 药食同源（食药物质）目录 | 可作食品 | 山药、茯苓、莲子、百合、酸枣仁、红枣、枸杞、桂圆、陈皮等 |
| 新资源食品 / 新食品原料 | 可作食品但有用量与人群限制 | 如人参有每日限量与孕哺禁忌——每种须逐一查公告原文 |
| 保健食品原料目录 | 普通食品不可用 | 褪黑素等 |
| 仅药品可用 | 食品禁用 | 任何药典药材但未入食品目录者 |

规则：配方里每一味都要能归到某一类并给出**当次检索的**依据；归不进去或查不到的，默认不能用。
性味禁忌（凉/温/热）不进对外内容，但要进内部客服话术（如薏米性凉、桂圆偏温、孕期人群提示）。

## 四、执行机制

1. 所有对外物料上线前过一遍红线词库；
2. 客服话术每季度按最新执法案例更新；
3. 「体质分层、人群禁忌」是内部服务能力，不是宣传素材；
4. 定位心法：合规不是创作的限制，是知音表达的护城河——越不能说功效，越要把「TA 想成为的样子」讲好。

## 五、易踩的三个「合规灰区」（实战教训）

1. **营养声称有标准管着**：「没加糖」「零添加」「低乳糖」这类声称受 GB 28050（预包装食品营养标签）约束，不是想写就写；声称了什么就要有检测数据支撑。且「没加白砂糖 ≠ 糖含量低」——原料自带糖（红枣、桂圆）会计入。优先策略：把糖做低，让营养成分表的真实数字说话。
2. **暗示也算违规**：监管看的是整体表达，不是单个词。「产品名（晚安）+ 成分（酸枣仁）+ 场景（睡前）+ 对比词（没有褪黑素）」的组合，即使没有一个功效词，也在暗示助眠功能。审查要按完整页面/完整脚本审，不是按词表审。
3. **产品类别决定标签义务**：最终执行什么食品类别（如固体饮料）决定名称标识与警示语要求——类别未定前，包装与详情页不能定稿。
