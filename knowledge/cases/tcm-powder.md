# 案例库 · 女性食养粉从 0 到 1（实战复盘）

> 本文件属于 knowledge/cases/（实战案例库）。**警告：本文件是单一项目（2026-08）的时点快照，仅用于演示流程的形态和深度。其中所有品牌名、数字（复购率 30%+、粉丝画像、39.9 价格等）、法规状态、原料结论，禁止作为事实复用到任何新项目——新项目的每个数字、每味原料、每条法规都必须重新调研取证。学它的「怎么拆、怎么写」，不学它的「具体答案」。**

一个真实走完五阶段的案例，供对照执行。行业：中式食养冲调粉；企业：有自有工厂（10 万级洁净车间、ISO22000+HACCP）、无老客、千川单品逻辑、毛利要求 ≥70%。

## 阶段 0 产出示例：资产盘点

读企业 PPT 与宣传册后得出：能做粉剂与液态饮；研发有高校中医智库背书；现有产品服务老人与婴幼儿（与目标女性人群无交集，等于 0 老客）。**关键纠偏**：企业宣传的「特膳」实为 GB 24154 运动营养食品标准，与女性食养人群不匹配——资产盘点不只是收集优势，更要拆掉错误的定位假设。

## 阶段 1 产出示例：标杆选择

主标杆：喜纯（女性食养粉）。达标理由：抖音女性粉丝 74–84%、核心 24–30 岁、复购率 30%+（蝉妈妈数据可查）；打法是内容驱动，不依赖我们没有的资源（无巨额代言、无线下渠道）。

## 阶段 3 产出示例：本地化重做

**产品**：三个配方对应一天三个「自我照顾时刻」——早安杯（山药谷物乳）、暖暖杯（山药桂圆乳）、晚安杯（山药莲子乳）。差异化核心：温县垆土铁棍山药（道地品种壁垒），全配方「去药材化」（无一味药材，零解释成本、合规安全）。关键论证：低乳糖奶粉 + 奶粉占比 ≤15%（乳糖不耐受真实有症状者约 16%，12g 为单次临界值）；甜味全部来自若羌灰枣（无添加糖，排雷点前置）；放弃 GABA（科学存疑 + 不能宣称功效 + 巨头已做烂）。

**人群心理图**：一个配方一张图。晚安杯示例——表层行为「下班后刷手机到深夜舍不得睡」；情绪真相「舍不得睡是补偿，缺的不是睡眠知识，是收场仪式」；理想自我「台灯下披着半干的头发捧一杯热的」；禁忌「绝不说教早点睡」。

**内容**：先定判断标准「是她想成为的样子还是狼狈的样子」，再写五屏脚本。「报复性熬夜」只留在内部文档，对外说「给今天收个尾」。

**包装**：调研后定「条装+外盒为主力（便携、适配 39.9 引流）、罐装守家庭复购、不做大袋装」；视觉上三配方共用新中式留白版式，靠色彩区分时刻（早安米杏金/晚安雾蓝紫/暖暖暖橘）。

## 这个案例里被纠偏最多的三个坑（新任务重点防范）

1. **跳过资产盘点直接套行业假设** → 阶段 0 不可省；
2. **详情页不自觉回到戳痛处**（「早晨手忙脚乱空腹的她」）→ 判断标准要在写内容之前立；
3. **配方含人参/黄芪等新资源食品，排除孕哺经期核心人群** → 每味原料先查法规身份与人群禁忌，再进配方。

## 附：V0.7 报告交付后，用户深度审查提出的第二轮纠偏（已固化进流程）

1. **定量论证不闭环**：用「12g 乳糖临界值」论证低乳糖必要，但 20g×15% 奶粉最多 3g 乳糖，论证自我矛盾 → 原则 5「数字论证必须自我闭合」；自检清单第 1 条。
2. **规格与宣称物理冲突**：20g 粉（约 80kcal）宣称「一顿正经早餐」→ 宣称必须与物理事实匹配，规格不匹配就改宣称（改为「晨间热饮/早餐搭子」）。
3. **结论强度超出证据**：「暖暖杯认知成本最低 → 应该首发」缺中间证据 → 证据不足以拍板时，设计小规模真实测试（真实用户盲测），不替市场做决定。
4. **缺品牌母价值观**：三个 SKU 各有情绪身份，但回答不了「品牌代表什么」→ 阶段 3 先定母价值观，再做 SKU。
5. **概念稿伪装成可执行**：报告把「原料概念表」写得像可投产配方 → 原则 6「区分概念级/生产级，显式标注」；自检清单第 8 条。
6. **判断标准过死**：「狼狈一律删」走向虚假完美人设 → 修正为「承认处境但不羞辱人格」（自检清单第 5 条双层标准）。
7. **定价照抄标杆**：「39.9 毛利≥70%」没有从自己的成本模型（履约/扣点/佣金/CAC/退款）倒推 → 定价只能从自己的单位经济模型推导，标杆价格结构只能当测试起点。
