# white-label-launch

> 白牌新品从 0 到 1 的完整策划 Agent Skill：从企业资产盘点出发，找到已被市场验证的标杆，拆框架不拆表面，复用框架重做自己的产品定义、人群心理图、内容表达与包装定价，全程证据驱动 + 来源标签，交付前经独立验证通道审计，最终输出完整立项报告。

## 这个 Skill 解决什么问题

给白牌/无老客基础的品牌做新品立项时，最常见的死法有三种：

1. **跳过盘点套行业假设** → 方案悬浮；
2. **抄标杆的表面**（文案、包装、达人名单）→ 在标杆主场拼资源；
3. **报告写得漂亮但无法判断哪些结论可信** → 决策层不敢执行。

本 Skill 用一条被两次完整实战验证过的流程对抗这三个问题。

## 核心机制

| 机制 | 一句话说明 |
|---|---|
| 五阶段流程 | 资产盘点 → 五重过滤找标杆 → 拆框架不拆表面 → 本地化重做 → 证据化报告 |
| 门禁（最多停 2 次） | 只在不可逆决策点停下：标杆锁定、内容判断标准 |
| 来源标签体系 | 每个关键判断强制贴标：[本人提供] / [已验证-来源] / [AI推测] / [AI结论] |
| 卡点 0 验证通道 | 交付前以对立视角重审全部产出，必须产出 verification-report.md |
| 失败模式库 | 21 条「翻车模式 → 检测信号 → 修正动作」，执行中对照预防 |
| 知识库分离 | 方法论（references/）跨品类通用；品类知识与案例（knowledge/）按品类生长 |
| 学习机制 | 每次用户纠偏沉淀为新的检查项与失败模式 |

## 使用方式

将本目录作为 Agent Skill 加载（兼容 Claude Code / Kimi 等支持 Skill 的环境）。触发示例：「帮我做一个白牌新品的完整立项」「对标 XX 的打法做我们的产品策划」。

## 设计哲学

- 拆框架，不拆表面——像素级模仿是在标杆主场送死；
- 纠偏是流程最大的价值来源，但卡点只设在不可逆决策上；
- 绝不编造数据、来源、案例；绝不伪造「用户已确认」；
- 纠偏不是一次性修补，而是流程的养料。
